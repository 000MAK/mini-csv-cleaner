# Mini CSV Cleaner

Trims cell whitespace, skips fully blank rows, and optionally removes duplicate rows. Does not overwrite the input file.

## Requirements

- Python 3.10+
- Standard library only; no `pip install` step required.

## Run

```bash
python main.py --help
```

## Example

`python main.py input.csv cleaned.csv --dedupe`

## Tests

```bash
python -m unittest discover -s tests -v
```

## Safety notes

Use copies of important files. Review output before using it in production. Do not add credentials, private data, or real customer files to Git.
